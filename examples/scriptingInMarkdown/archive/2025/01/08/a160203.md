As part of the conversion of [BingeWorthy](https://tv.bingeworthy.org/), I started the database from scratch, but before I did that, I exported [all the data](https://github.com/scripting/binge2Data/tree/master/data) and put it in a GitHub repo. This included a JSON file of ratings for each user. For example, [this](https://github.com/scripting/binge2Data/blob/master/data/users/davewiner.json) is my file. Remember we used Twitter identity then, _davewiner_ is my Twitter username, just replace my name with yours to see your file, if you were a Bingeworthy user in the past.
