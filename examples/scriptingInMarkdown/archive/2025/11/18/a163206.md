![](https://imgs.scripting.com/2023/05/17/theBrain.png)I'm looking into the problems in feedlanddatabase I [mentioned](http://scripting.com/2025/11/17.html#a174327) yesterday. I bet it'll turn out there are a bunch of issues that have been there for a long time, but don't show up in the user interface of the product. I'm still developing good techniques for debugging Node.js server apps. Recently, I've developed new tools that make these bugs show themselves, like [socketdemo](https://socketdemo.feedland.com/). I added some new capabilities to it in the JavaScript console that make the updates visible. If you open the console in the debugger while it's running you'll see what I'm talking about, [screen shot](http://scripting.com/images/2025/11/18/console.png). Sometimes to debug a problem that doesn't have a UI you have to give it a UI.
