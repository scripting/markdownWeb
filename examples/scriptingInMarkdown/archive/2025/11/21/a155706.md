I'm continuing to work on the way FeedLand detects changes in feed items. This morning I did a careful study of the function that gets a guid for an item in conjunction with ChatGPT. It would be so much easier if RSS 2.0 required an item-level <guid> element, but it doesn't. That was the philosophy, all item-level values are optional. My notes are [here](https://github.com/scripting/feedlandDev/issues/11#issuecomment-3563675430).
