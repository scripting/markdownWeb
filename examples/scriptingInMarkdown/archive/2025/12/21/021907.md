![](https://imgs.scripting.com/2024/12/25/leftfacingsanta.png)In 2026 and beyond, web devs will build on WordPress as if it were as crucial a part of the web infrastructure as the web browser or server, but performing a different but essential function that has been missing for the weird reason that few web developers know it is there.

This has been one of the big problems in tech as journalism beyond rewriting press releases has been gone for a couple of decades. No way to get news out about new developments. We have to fix that too, btw. ;-)

Yours in support of the forgotten freedom of the world wide web.
