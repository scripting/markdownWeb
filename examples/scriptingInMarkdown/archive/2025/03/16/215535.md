[Adding and deleting categories](https://www.youtube.com/watch?v=Vxdv5PveIDM) are part of [WordLand](https://wordland.social/) 0.50, released earlier today. These are the same categories you can edit in the WordPress user interface. But I learned that you need to be able to add categories when you're writing. You want this functionality to be close-by.

[Two columns](https://imgs.scripting.com/2025/03/16/twoColumnScreenShot.png) in the Categories dialog. More efficient use of space.

[Context menu](https://imgs.scripting.com/2025/03/16/contextMenuScreenShot.png) with two new commands.

Change notes [are here](https://github.com/scripting/wordlandSupport/issues/59).
