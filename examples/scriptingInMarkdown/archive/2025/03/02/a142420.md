![](https://imgs.scripting.com/2017/09/12/pitcher.png)If I understand correctly, this [TechCrunch article](https://techcrunch.com/2025/02/28/bluesky-based-instagram-alternative-flashes-launches-publicly/) is misleading the same way the Bluesky company misleads. There is no benefit to users of either app that they use the same complicated and new structure to communicate, where simpler and established standards would work just as well. There is a way they could make this work. Come up with a plugin architecture and something like an app store, so developers could define new data types, and then we'd really have something. I would probably do an [outliner](https://opml.org/) plugin first, then a [Markdown](http://scripting.com/2022/08/25/210902.html) plugin.
