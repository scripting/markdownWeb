![](https://imgs.scripting.com/2025/08/27/quakerOats.png)The last few days we've been [exploring](https://this.how/web/what.opml) the ideas behind the web, to decide what, if anything that we're doing today is either _on_ the web or _of_ the web. On the web seemed relatively easy. But of the web is a bit more elusive. Until [Ken Smith](https://x.com/KenSmith/status/1960475445457039601) found [this quote](https://www.w3.org/History/1989/proposal.html#:~:text=%22Hypertext%22%20is%20a%20term%20coined,together%20in%20an%20unconstrained%20way) of [Ted Nelson](https://en.wikipedia.org/wiki/Ted_Nelson) in the original 1989 proposal by [Tim Berners-Lee](https://en.wikipedia.org/wiki/Tim_Berners-Lee) for what would become the web. "Human-readable information linked together in an unconstrained way." I like this, because it, like the definition I came up with for [weblog](https://archive.blogs.harvard.edu/whatmakesaweblogaweblog/), talks about the activity as opposed to the technology. Human-readable is essential. And most essential is "unconstrained." If something requires a link, you should link to it. If you don't it ain't the web.
