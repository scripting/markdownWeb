![](https://imgs.scripting.com/2022/12/23/masto.png)BTW, I've started [using Mastodon](https://mastodon.social/@davew/112971977589934892) in place of GitHub for comments on posts like the one [below](http://scripting.com/2024/08/16.html#a133136). GitHub has a better model for text with comments, supports full Markdown the way it was meant to work. I have an instance of Masto that I can use that supports Markdown but they do an [unacceptable](https://imgs.scripting.com/2024/08/16/thisIsNotALegitWayToDisplayALink.png) rendering of links. [Example post](https://social.masto.land/@dave/112971999302900967). I want a simple, widely accepted easy place to comment, on the social web, not Discourse or GitHub, that isn't controlled by one vendor (so ActivityPub for now is probably the best approach) and supports plain old Markdown without any weird embellishments. I don't work in the Mastodon world, I'm already committed to the projects I'm doing. But we could really use something nice, designed to plug into blogs. This is a good use-case, and it's pretty close.
