The Twitter API still works, with some serious limits. Not easily incorporated into products, but useful for individuals with developer accounts. Not an insurmountable hurdle, it seems, though I was a developer from before. A few bullet points.

*   My linkblog now reliably works on [Twitter](https://x.com/davewiner) and [Threads](https://www.threads.net/@davew), in addition to [Mastodon](https://social.masto.land/@dave), [Bluesky](https://bsky.app/), [RSS](http://data.feedland.org/feeds/davewiner.xml) and [WordPress](https://linkblog3.wordpress.com/).
    
*   I was confused about the status of the Twitter API, but it turns out it's still there, and there is a [package](https://www.npmjs.com/package/twitter-api-v2) that connects to it for Node apps.
    
*   It took me a few hours to add [support for Twitter](https://github.com/scripting/textcasting/blob/main/textcasting.js#L543) in my [textcasting](https://github.com/scripting/textcasting/tree/main) server app which is how my software connects to all the various services.
    
*   I should probably add a plugin abilitiy for textcasting so that other services could easily be added, without modifying the core app. Totally doable. It's already factored that way internally.
    
*   I should probably write [some docs](https://github.com/scripting/textcasting/blob/main/README.md) for it too. :smile:
    
*   Anyway, the [deal with Twitter](https://developer.x.com/en/docs/x-api/getting-started/about-x-api) is that it's free for up to 1500 posts per month, as I read it, which seems manageable for one person (me), but no way is it enough for a community of users.
    
*   Why connect to Twitter? People are there. Until they aren't we're going to need a way to push stuff to Twitter.
