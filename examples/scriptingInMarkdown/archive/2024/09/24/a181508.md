Now that ActivityPub is [claiming](https://socialwebfoundation.org/2024/09/24/launch/) to be the [Social Web](https://en.wikipedia.org/wiki/Social_web), I feel like Lloyd Bentsen at the [debate](https://en.wikipedia.org/wiki/Senator,_you%27re_no_Jack_Kennedy) with Dan Quayle. ActivityPub is not the web any more than Dan Quayle was Jack Kennedy. The web is simple. That was hard to do. Very little since then lives up to that standard of simplicity, definitely not ActivityPub. The web is the web is the web is the web etc. Pick another more humble name. If it ever does achieve the utility of the web does we can take another look.
