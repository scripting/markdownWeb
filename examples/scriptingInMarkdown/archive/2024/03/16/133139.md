As I complete a big project I like to re-center, to remind myself what I'm working for.

My goal is to create a _social web_ that includes blogs and twitter-like systems. To set a new [baseline](https://textcasting.org/) where titles, simple styling, links, enclosures and the ability to edit are tools writers can use.

Somehow twitter pushed writing into a tiny little box. If we work together we can dig ourselves out of this box.
