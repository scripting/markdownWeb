DNS fix: [pagepark.scripting.com](https://pagepark.scripting.com/) now redirects to the [GitHub repo](https://github.com/scripting/pagePark/) for PagePark. Somehow I lost the pagepark.io domain, but I don't really want it, so it's kind of ok. But there are some broken links. I recall there was a nice site with menus and stuff that was built from the GitHub repo but archive.org isn't able to [find](https://web.archive.org/web/*/pagepark.io) it for some reason. Moral of the story, don't buy so many domain names thinking you're really clever. But of course I still do. Someday they'll all be gone, of course.
