![](https://imgs.scripting.com/2026/05/19/reallySimpleNet.png)When writing code with Claude you really have to be skeptical when it says it just found the problem, but you have no idea what it's saying, chances are pretty good it's just a word salad excuse for not having read all the code necessary to have an fact-based opinion. Actually debugging software isn't about opinions, it's about proof. When you start clutching at straws until one works you just added another level of bug that will eventually bite you in the butt and you'll still have to solve the original one. Uncorrected, I'm pretty sure you wouldn't want to trust the code it writes, but I guess that's why people have two or more instances playing different roles? For now I'm the one that questions its sanity, politely though. ;-)
