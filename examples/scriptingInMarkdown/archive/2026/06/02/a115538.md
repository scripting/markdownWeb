![](https://imgs.scripting.com/2023/11/27/rssClub.png)The only twitter-like system that does text right is Elon Musk's X. I find that somewhat ironic. It's also the only twitter-like system where there's any kind of an actual community. They also have an API that works, has been around for more than a couple of years, and doesn't have a W3C working group messing with it. There's a lot of hype flying around, and we don't have any real journalists covering it so there is no real source of truth. I think the entrepreneurial twitter-likes should stop thinking in terms of owning the web and start adding back the text features the original Twitter thought the web didn't need, over 20 years ago.
