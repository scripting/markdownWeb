The source code for my [podcast builder](https://github.com/scripting/podcastBuilder/) app is [open source](https://github.com/scripting/podcastBuilder/). Of course I use my outliner to edit the [OPML file](https://github.com/scripting/podcastBuilder/blob/main/examples/scripting/podcast.opml) for the podcast text and link in the enclosure. I recommend [opening](https://drummer.land/?url=https://raw.githubusercontent.com/scripting/podcastBuilder/refs/heads/main/examples/scripting/podcast.opml) it in Drummer. To see how the atts work, click on the suitcase icon with the cursor on the main head for each episode. The new att is enclosure, which is the URL of the audio for the podcast. Drummer automatically fills in the length and type.
