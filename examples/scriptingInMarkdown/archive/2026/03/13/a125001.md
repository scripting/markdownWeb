We're still fixing problems created by the switch to https on the web. Reported a problem [yesterday](http://scripting.com/2026/03/12/183605.html), was surprised to find an inconsistency in the way WordPress represents guids in its RSS feed for a post and in the API. This morning I posted [an issue](https://github.com/Automattic/wp-calypso/issues/109266) on the WordPress repo on GitHub. I don't think they can fix either approach without breakage, so they probably have to leave it as-is. I updated wpIdentity package to normalize guids it gets from the API to lowercase, so even if they change the implementation my software won't break. Another reason we're still paying for what Google decided we needed. What we _don't_ need -- BigCo's f-ing with the f-ing web.
