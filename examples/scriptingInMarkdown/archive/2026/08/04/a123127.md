Last week along with a lot of other stuff, we shipped a [validator](https://github.com/scripting/rss.chat/blob/main/network/docs/validator.md) for lists and feeds that want to be compatible with RSS.chat. It works best for standards to stay strong and a validator helps that. So here are a few examples, validating [one user's feed](https://valid.rss.chat/?url=https%3A%2F%2Frss.chat%2Fusers%2Fdave%2Frss.xml), validating the [everyone feed](https://valid.rss.chat/?url=https%3A%2F%2Frss.chat%2Fusers%2Frss.xml) for RSS.chat, which is interesting because this feed starts a lot of threads, so we navigate through that tree and check those feeds too. And validating the [user list](https://rss.chat/data/subs.opml) on RSS.chat, which is an OPML file. And a [simple feed](https://valid.rss.chat/?url=https%3A%2F%2Fvalid.rss.chat%2Ftests%2Fmanyproblems.xml) with a few interop isses.
