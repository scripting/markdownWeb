![](https://imgs.scripting.com/2026/02/23/reallySimpleRavioli.png)Taking some time off to breathe and regain perspective. Fixed a few bugs, and wrote about the big picture on [demo.rss.chat](https://demo.rss.chat/?id=378). I really want to get a project going to peer with [standard.site apps](https://standard.site/) running in AT Proto, both ways, from us to them, and from them to us, via RSS. We can peer with them because as far as I can tell they implement [textcasting](https://textcasting.org/). This bridge would demonstrate something important. When something interesting shows up not based entirely on web standards, we're flexible if the attraction is strong enough. This is how the [internet](https://en.wikipedia.org/wiki/Internet_protocol_suite#History) came to be. Our systems are prepared to create bridges. And unlike bridging between systems that have different ideas of what text is, which are basically hopeless, if we agree that the [web standard for text](https://www.w3.org/History/19921103-hypertext/hypertext/WWW/MarkUp/Tags.html) is fine for writers and reader, better than the ridiculous limits imposed by twitter-like systems. Writing on the web has been crippled since Twitter, now let's start building it back up. That's the appeal of standard.site, they are working toward the same goal. We should work together.
