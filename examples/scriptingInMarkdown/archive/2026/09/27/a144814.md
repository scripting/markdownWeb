[Milestone](https://tmp.userland.com/). We were able to get the DocServer site for Frontier to build. Here's the page for the [file verbs](https://tmp.userland.com/file/default). And within that group the page for [file.copy](https://tmp.userland.com/file/copy). It worked the first time, but there were errors in the new kernel that were fixed. The site [looks dated](https://imgs.scripting.com/2026/09/27/fileCopyScreen.png), of course -- it was created in the 90s. We will update the CSS to be more like the [DocServer site](https://docserver.scripting.com/?verb=file.writeWholeFile) for Drummer, which was done a couple of years ago. Almost everyone on the team contributed to this site, Wes Felter, Andre Radke, Jake Savin, Brent Simmons, and myself. I see there names a lot and it makes me happy to see this group effort preserved.
