![](https://httpproxy.scripting.com/?url=http%3A%2F%2Fimages.scripting.com%2FarchiveScriptingCom%2F2007%2F05%2F19%2FhouseOfCards.gif)WordPress has a product that could be shaped into a Substack competitor. With a beautiful user interface for writing. WordPress is its OS, but most users never see it, the same way most web users never see the command line. But technical users can get under the hood and tweak things. And unlike Substack, it lets their users write with different editors, thus forming a [coral reef](https://daytona.scripting.com/search?q=%22coral%20reef%22) for a new platform. _Wordpress could be the OS the web never had._ I still believe this as I see Automattic and WordPress flail. If we were starting a new future for the web, no one would have time for corporate intrigue. Look at how far from the idea of blogging we've strayed. How far should this go before I comment? Well, I decided it's time.
