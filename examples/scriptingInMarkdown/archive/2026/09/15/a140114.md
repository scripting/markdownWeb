![](http://images.scripting.com/archiveScriptingCom/2007/02/16/bird.jpg)In many ways JavaScript is a better language than UserTalk. For example I miss JSON constants. I miss certain language constructs, like conditional assignments. We don't have the idea of a const. On the other hand, JavaScript doesn't have environment features Frontier has. I want to have Atlantis run JavaScript the same way Cancoon (the codename for the kernel of Frontier before this version) ran AppleScript.
