In the age of AI, Markdown is even more the default choice for text, something I heartily [approve](https://textcasting.org/#1683751572000) of. And that's why I think now is a good time to sneak some new open non-silo'd technologies in there, like for example, WordPress. Open source is not the only reason WordPress is valuable, it also supports all the standards of the web. It means WordPress can tie together text on the web in a way nothing else can, and it works really well with Markdown.
