It's a standard REST API.

Here's the [server side](https://github.com/scripting/rss.chat/blob/main/server/code/rssnetwork.js#L2037) of the API.

Here's how you call it from [browser-based JavaScript](https://github.com/scripting/rss.chat/blob/main/client/code/api.js). You can include that code in your apps.

Here's an [example app](https://github.com/scripting/rss.chat/tree/main/examples/easyblogger) that implements a simple blog builder for my recent posts on RSS.chat. We were thinking about doing this as a project for Claude and myself but decided it would be more fun to let devs see what they can do here. :-)

And finally here are the [docs](https://github.com/scripting/rss.chat/blob/main/server/docs/api.md) for the API itself.
