The browser and the web it defines is a hairball in a hairball in a hairball in a hairball in a hairball.

The hairballs are named Chrome, Firefox, MSIE, Netscape, Mosaic.

Each in turn has [had their way](https://www.merriam-webster.com/dictionary/have%20one%27s%20way%20with) with the web.

The stack of hair defines a "web" that is far far away from the [web](https://www.w3.org/History/1989/proposal.html) we started with.

The tech industry kicked the web out of the web.

It was going pretty good for a while, if you could live with the all the modal [popovers](https://daringfireball.net/2026/05/what_is_a_dickover) and paywalls, but now the current owners are [excluding](https://this.how/googleAndHttp/) old sites, and imho when you do that, it's not the web any longer.
