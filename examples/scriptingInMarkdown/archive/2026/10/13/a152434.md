[firstSentence](https://gist.github.com/scripting/5e9a9a1d79f13176f8b6b11dd3da6cbf), a JavaScript function that returns the first sentence in a string. Useful in coming up with something to display for an untitled post. It's always been a klooge, but this time with Claude's help we're using a new API in JavaScript, and supposedly it really works. I'm using it in one of my apps, and you might find it useful too, and let me know if it works for you.
