![](https://imgs.scripting.com/2026/09/12/plato.png)Reminder, [Atlantis](https://daytona.scripting.com/search?q=Atlantis) is the codename for the new Frontier that runs in Electron. As I work on other projects now, it's not on my front burner, but in a way it is, because I'm using it constantly as I work on FeedLand and the other project. We just released a new set of parts that make it possible for it to open a Markdown file for reading when you 2-click on it in the Finder. Things like that are great to add, because they fit into the 2026 web environment. How did I discover that? Accidentally 2-clicked on a .md file, expecting Atlantis to open it, and it just sat there. Filling in things like that. And for some reason it can't get the find command ported from the C kernel to the new JavaScript one. I have told it countless times that the source of truth is the 2014 repo. I told it again. A neat way to follow this project is to subscribe to the [codecasting feed](https://bits.codecasting.org/frontier.root/rss.xml), the comment for each new part release gives you an idea where some of the work is going on.
