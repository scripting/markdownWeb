Since Andrew is working on a new version of the [rssCloud](http://home.rsscloud.co/) server now, he asked if it would make sense to support [OPML](http://opml.org/) in rssCloud. That would mean adding a <head> element that had all the info that's in the rssCloud element in an RSS feed. It's a good idea, but.. (sorry) -- OPML already has a realtime notification service, it came after rssCloud and is based on [web sockects](https://en.wikipedia.org/wiki/WebSocket). It's the core tech behind the \[%search: Instant Outliner%\], a protocol that [LO2](http://littleoutliner.com/) implements.
