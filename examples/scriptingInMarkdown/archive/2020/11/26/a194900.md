Here's [my vignette](https://twitter.com/davewiner/status/1331877787582525440). "Dave has been ordered to add a feature to the app, and asked to explain why it’ll take so long to do. Finally Gruber in a fit of frustration asks for the source so he can add it himself over the holiday weekend. Dave gives him the code and starts work on a fresh project."
