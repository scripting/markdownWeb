Just trying out [Glitch](https://glitch.com/), very interesting system, looks like what I hoped [Heroku](https://duckduckgo.com/?q=site%3Ascripting.com+heroku&t=h_&ia=web) would be, esp that now they have a way to run real server apps (no limits). [$10 a month](https://www.theverge.com/2020/4/15/21220438/glitch-boosted-apps-subscriptions-coding-platform-anil-dash). Certainly worth checking out now as more than a curiosity.

![](https://imgs.scripting.com/2020/04/15/fishbowl.png)Is there a simple no-frills doc that explains the model for apps. How the filesystem works, how to access an app over HTTP. Can my app have an IP address? How do I know what port to use (port 80 gets me an error). I have succeeded at connecting to my app over HTTP but it comes embedded in something they constructed. Obviously this won't work for serving my non-experimental apps. I understand it's set up for newbies, that's cool. Now how do I strip it down so it works for its new intended purpose?

I've opened a [thread here](https://github.com/scripting/Scripting-News/issues/168). I know I've asked some of these questions before, btw -- but I'm approaching it now in a different way.
