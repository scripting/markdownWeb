![](https://imgs.scripting.com/2020/04/30/voila.png)On Twitter it was [suggested](https://twitter.com/bloatedlesbian/status/1255697398485180418) that I change the titles of the items in the Cuomo Briefing podcast [feed](http://xmlviewer.scripting.com/?url=http://scripting.com/cuomo/rss.xml) so each item has a unique title, that it might start working properly in Apple's podcasts app on my iPhone. Note the items in the feed have [proper guid elements](http://scripting.com/images/2020/04/30/feedHasGuidsAsYouCanSee.png), so there should be no need to use the title as a guid, but it seems that Apple's podcast app does, because when I changed the titles of the five most recent episodes, voila -- they show up in the Apple podcasts app. This was suggested on Twitter by [OG](https://www.dictionary.com/e/slang/og/) podcaster [Madge Weinstein](https://twitter.com/bloatedlesbian/status/1255697398485180418). Bottom-line: there appears to be an easy-to-fix bug in Apple's podcasts app on iOS.
