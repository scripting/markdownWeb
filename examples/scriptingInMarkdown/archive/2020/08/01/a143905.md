Every month I archive the OPML source for the [previous month](https://github.com/scripting/Scripting-News/blob/master/blog/opml/2020/07.opml), including all the metadata, to a [public GitHub repository](https://github.com/scripting/Scripting-News/tree/master/blog/opml), so you can see how the data flows. There are lots of conventions in the form of attributes on OPML `<outline>` elements. This is the data that [Old School](https://github.com/scripting/oldSchoolBlog) uses to render [the HTML](http://scripting.com/) you see on the web. At some point when the dust clears from my other projects, I'll hook up [LO2](http://littleoutliner.com/) outlines to Old School in some fashion. They're already pretty close, kind of the way [San Francisco and Marin County](https://www.google.com/maps/place/Golden+Gate+Bridge/@37.8199328,-122.6183308,11z/data=!4m5!3m4!1s0x808586deffffffc3:0xcded139783705509!8m2!3d37.8199286!4d-122.4782551) were almost connected before a [bridge](https://en.wikipedia.org/wiki/Golden_Gate_Bridge) was added.
