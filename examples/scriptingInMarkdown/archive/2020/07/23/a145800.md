Good progress on the new BingeWorthy. The big difference in this version is that you can submit programs, no need to go through me. How it works. Find the page for the show on [Metacritic](https://www.metacritic.com/). Choose the _Submit a program_ command from the _Main_ menu. Enter the URL of the page. The server reads the file on Metacritic, extracts the Facebook and Twitter metadata from the page, using the title in our database. I just want to be sure it's a real program, keep out the spam. I have some ideas for new UI's. But the main goal, as before, is to learn about worthwhile streaming programs.
