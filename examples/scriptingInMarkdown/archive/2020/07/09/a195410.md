I discovered a [new feature](http://scripting.com/images/2020/07/09/featureInGitHub.png) in GitHub. If you create a public repository with the same name as your account, the [readme.md](https://github.com/scripting/scripting/blob/master/README.md) file in that repo is displayed on your [GitHub home page](https://github.com/scripting). Of course it's Markdown. Might be interesting to integrate some of the status-editing features I'm working on into this. It supports basic web stuff, as you would expect from a techies site like GitHub. Okay this might be fun. :balloon:
