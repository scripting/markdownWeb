I turned off the [Likes feature](http://likes.scripting.com/) on Scripting News. Most people are reading the stuff through email and RSS. Likes predates the email distribution. The server is a bit of a hog. But the most important thing was that it wasn't being used. If it had gained traction I would have been ready to do the work to get it smoothed out. The code is still there, the server is still running, so I could turn it back on any time.
