It turns out the [source](https://github.com/scripting/Scripting-News/issues/150#issuecomment-581407743) of the problem that a user was experiencing with the new version of [Little Outliner](http://littleoutliner.com/) was [Privacy Badger](https://www.eff.org/privacybadger) from EFF. I gather it's something that a user can disable, so if you have [LO2](http://littleoutliner.com/) and you're running Privacy Badger, you should disable their distrust of scripting.com and then LO2 should work as it should.
