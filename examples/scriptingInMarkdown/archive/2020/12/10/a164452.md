![](https://imgs.scripting.com/2020/12/10/drinkByEmma.png)Why I need a [JavaScript-like scripting language](http://javascriptscript.com/). I had a bug in a script I use to backup various files from my blog in a [GitHub repository](https://github.com/scripting/Scripting-News/tree/master/blog). It was simple enough to fix, but the script stopped working 27 days ago, so now I have a hole in my repo with all the missing days. This is the kind of problem you solve with a scripting language. Doing this in standard JS is going to be a pain in the ass. But I'll do it because I care. But things could be so much better.
