The [OPML package](https://github.com/scripting/opmlPackage) is pretty stable. I'm using it in all my JavaScript browser and Node projects. It would be great if people would [port it to other environments](https://github.com/scripting/opmlPackage/issues/10). Make it easy to do a great job of supporting the format used [for](http://scripting.com/2014/03/21/theWebIsMadeOfInterop.html) outliner [interop](http://scripting.com/2021/12/16/153331.html?title=myProductIsInterop) and RSS subscription lists.
