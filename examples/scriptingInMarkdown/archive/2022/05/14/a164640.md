![](https://imgs.scripting.com/2022/05/14/beatles.png)There was a time back in the early-mid 00s, that I hoped the [World Outline](http://daytona.scripting.com/?q=world%20outline&collection=scriptingnews) would be the future of the web. Much later, in 2015, I ported the World Outline software from Frontier running as a server, to Node.js, but I left the site private, probably because I wasn't planning to build in this direction, I just wanted to get some sites that were running in Frontier to work in Node. This morning some of my work led me to this software, and I saw that it was private, and [made it public](https://github.com/scripting/worldOutline). Basically the _wo_ is like the _www_ except with outlines instead of HTML. You can of course render the outlines as HTML, and that's what the WO software does. Given all the interest in outliners these days, it seemed like a good time to open this stuff up. However at this point I don't plan to run the server software here. If you get it running, all I ask is that you continue to support OPML. Interop is everything. Thanks.
