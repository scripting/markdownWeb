TL;DR -- there's a new _expandIncludes_ function in the [OPML package](https://github.com/scripting/opmlPackage#v0424----51122-by-dw) for JavaScript.

As you know I'm working on a refresh of all the stuff I have related to [RSS](https://cyber.harvard.edu/rss/rss.html), and part of that is the use of [OPML](http://opml.org/) for subscription lists.

A [subscription list](http://opml.org/spec2.opml#subscriptionLists) is an outline containing nodes of type _rss_ that have an _xmlUrl_ attribute that points to a feed. Even though the type is rss, it can be used to point to feeds in any format, including Atom and RDF.

The lists can contain anything else you like, feeds, docs, and they can include other subscription lists.

Example: You could maintain a list of people you follow and plug that into your reader's subscription list, and also offer it to friends, where they could include it in their list. And because you're using pointers, when your list updates, your friends are automatically updated.

To include a list in another, just insert a node of type _include,_ with a _url_ attribute that points to another OPML file which should include nodes of type _rss_ and possibly other _include_ nodes.

They work like [includes in C](https://en.wikipedia.org/wiki/Include_directive#C/C++), which is where the name came from.

Anyway, the new thing is that the [OPML package](https://www.npmjs.com/package/opml) now has an [expandIncludes](https://github.com/scripting/opmlPackage/blob/main/opmlpackage.js#L322) function that can be given an outline, in a JavaScript object, and it returns an outline with all the include nodes expanded.

I've had code that does this for decades in various environments. It's trivial in a language like C, Python, or Frontier -- any rational language that takes care of I/O under the hood, but it's a difficult problem in a language like JavaScript where you have to manage your own synchronization. This code first appeared in 2014 as part of PagePark, then moved to the daveopml package, and finally, today into the [opml package](https://www.npmjs.com/package/opml). This is where it belongs, where everyone else can easily get to it.

The new version, 0.4.24 is [on GitHub](https://github.com/scripting/opmlPackage) and [in NPM](https://www.npmjs.com/package/opml). There's a [release note](https://github.com/scripting/opmlPackage#v0424----51122-by-dw) and [example code](https://github.com/scripting/opmlPackage/tree/main/examples/includes) with an [OPML file](https://github.com/scripting/opmlPackage/blob/main/examples/includes/includes.opml) that illustrates.

If you have questions or comments post an [issue](https://github.com/scripting/opmlPackage/issues) in the repo.
