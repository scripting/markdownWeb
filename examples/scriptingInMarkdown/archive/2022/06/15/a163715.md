I added a new feature to the [reallysimple](https://github.com/scripting/reallysimple) package. Now it looks for an [atom:link](https://stackoverflow.com/questions/48138258/how-do-you-add-atomlink-with-rel-self-to-an-rss-document) head-level element with rel="self" and if it's present, it then adds the _href_ value to the feed object with the name _linkToSelf._ Here's an example of a feed, [Don Park's blog](https://blog.docuverse.com/feed/), that has this element, and here's [what reallysimple generates](http://feeder.scripting.com/returnjson?url=https://blog.docuverse.com/feed/). I felt it was good to include this because this use of atom:link is pretty common, and I wanted to make a gesture, that this isn't about supporting any single feed format, rather it's about supporting what's out there and useful.
