![](https://imgs.scripting.com/2022/06/09/sanders.png)I'm happy to report that finally there's a reasonable app running at [xmlviewer.scripting.com](http://xmlviewer.scripting.com/?url=http://scripting.com/rss.xml). I used the [Ace Editor](https://ace.c9.io/) in read-only mode to view the contents of the XML file provided as the _url_ parameter. If no URL is provided I show the [RSS feed](http://scripting.com/rss.xml) for Scripting News (my blog). There are still a couple of problems, at least, with the vertical and horizontal scrollbars. Ace has a great community and everything in the software is configurable, but I've had trouble at times putting it all together. I'll swing back to this at some point, but in the meantime what's [there now](http://scripting.com/images/2022/06/09/xmlViewerToday.png) is far more useful that what's been there [since 2011](http://scripting.com/stories/2011/02/25/viewingRssInABrowser.html).
