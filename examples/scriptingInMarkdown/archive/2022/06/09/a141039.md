I've [asked](https://github.com/scripting/Scripting-News/issues/234) about getting something like the code-displayer on GitHub to use in a package. I think I found one today, [highlight.js](https://highlightjs.org/static/demo/). It's not exactly the style of the display on GitHub ([example](https://github.com/scripting/tweets.opml.org/blob/main/users/davewiner/2022/06.json)), but it does provide syntax coloring which is one of the basic features. I want it for an app I'm doing to display the result of converting an RSS feed to JSON. I want it to look good, for devs to immediately understand what they're looking at.
