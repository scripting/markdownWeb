![](https://imgs.scripting.com/2021/09/17/simpsonsBeeGuy.png)Looking for a LogSeq plugin developer: As you may know, I've written a [Node app](https://github.com/scripting/myLogseqBlog) that flows LogSeq journal writing to a Drummer blog. Here's an [example](http://oldschool.scripting.com/KLTransit/). It does the whole thing, except it should be baked into LogSeq. Setting up a Node app and running it externally is both too difficult for an average user and too many steps. We already have a [great techie user](https://github.com/scripting/myLogseqBlog/issues/1#issuecomment-1013997158) who I worked with me to get the Node app working, who is up to speed on using the software. He can guide the process, we just need a dev to work with him. I'm available to help too, to the extent that I can. If you are a LogSeq plugin dev, please post a note in [this thread](https://github.com/scripting/myLogseqBlog/issues/1), and we can hopefully get started right away. _Thanks!_
