As we're starting to test the Linux and Windows versions of Electric Drummer there have been some basic questions. I thought I should respond publicly so people understand what we're doing.

*   [Electric Drummer](http://docserver.scripting.com/drummer/electricDrummer.opml) or E/D for short, is an app that runs on the desktop, hosted by its operating system. Like a word processor or a graphics program. It's most like [Slack](https://slack.engineering/building-hybrid-applications-with-electron/) or the [Atom](https://atom.io/) editor, but it's [Drummer](http://daytona.scripting.com/?q=drummer&collection=scriptingnews), a multi-tab outliner for note-taking, organizing and publishing.
    
*   It runs in [Electron](https://en.wikipedia.org/wiki/Electron_\(software_framework\)), a beautiful environment that makes cross-platform apps easier to create and manage.
    
*   E/D saves files on your local file system as any desktop app does.
    
*   It can also hook up to your web Drummer account for outlines that you want to make public. It's how I do [Scripting News](http://scripting.com/). The outline that I edit is on my local system,. It's also a [public file](http://drummer.scripting.com/davewiner/blog.opml), so it can be accessed by the CMS when I ask it to render my blog from the outline. The public file is stored in my web Drummer account. It's a nice combination.
    
*   E/D is a scripting system, like web Drummer is. It will be able to access the local file system, and also will be able to run a server, none of which are possible from the web app.
    
*   There is already a [Mac version](http://docserver.scripting.com/drummer/electricDrummer.opml) of E/D that has been available since October 10, when Drummer shipped.
    
*   It's the same as web Drummer, a few commands work differently because it runs in a different place, but it's the same code, same outliner, same UI, same bugs (!), etc.
