A [utility](http://scripting.com/code/opmltojson/) I wrote a while back that converts an [OPML file](http://scripting.com/code/opmltojson/?url=http://this.how/blackLivesMatter/?format=opml) from XML to JSON. It's exactly the same outline either way. If people prefer to use JSON to XML for outlines, this is how to do it. I've written a lot of JavaScript code that assumes exactly this structure.
