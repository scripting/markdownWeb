![](https://imgs.scripting.com/2019/09/14/rssCoffeeCup.png)BTW, since RSS is rebounding (yay!) -- I have a [Node.js package](https://github.com/scripting/reallysimple) that makes reading an RSS feed a one line call. It factors out all the variability, and returns a consistent JavaScript object. Reading an RSS feed is as easy as reading a JSON file. I promise. No bullshit. And btw, it also reads Atom and RDF through the same interface. You don't even have to know what format the file is, all that is taken care of. The point is, reading an RSS file was too hard. So I spent the time to make it simple and easy.
