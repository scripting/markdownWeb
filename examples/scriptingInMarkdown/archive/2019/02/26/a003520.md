Idea for people working on new identity services. Let's come up with a common API for them, so you can plug new services into apps that use identity. Sort of like [jQuery](https://en.wikipedia.org/wiki/JQuery) but for identity. (Reminder: jQuery was created because browsers had incompatible APIs. jQuery flattened them all out. A very valuable piece of tech.)
