This has been a puzzle for a while, since I reprovisioned one of my servers on Digital Ocean. It had been on AWS.

One of the [apps](https://github.com/scripting/nightlyRss) on the server is set to run at midnight but it was running at 7PM. It had been working properly on the other server.

To find out why, I logged on the server in the Terminal app, and ran the _date_ command. It responded that it was 4PM, with the timezone as Z, which stands for Zulu or Greenwich, England. So that appears to be the problem.

I tried [setting the time](http://scripting.com/2019/01/23.html#a150652), but that had no effect. It still thought it was 4PM and the server was in Greenwich.

Then I tried [setting the timezone](https://help.ubuntu.com/community/UbuntuTime#Using_the_Command_Line_.28terminal.29) from the command line. Now it says the server is in EST and it's 11AM. So hopefully that will fix the problem and the app will do its thing at midnight instead of 7PM.
