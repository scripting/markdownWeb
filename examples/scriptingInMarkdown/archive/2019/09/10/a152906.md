![](https://imgs.scripting.com/2019/09/10/xmlRpcBookOReilly.png)Here's a new version of my [XML-RPC for JavaScript](https://github.com/scripting/xml-rpc#readme). There's a [client and server](https://github.com/scripting/xml-rpc#readme) for Node, and a client for the browser. A [debugger](http://scripting.com/code/xmlrpcdebugger/) you can enter a call in, see what goes over the wire and what comes back. If you're using XML-RPC in JavaScript, please consider using this package and [give feedback](https://github.com/scripting/xml-rpc/issues/9). If you have a current implementation for any environment, please post a note here. In my next pass I plan to make the [rebooting page](http://reboot.xmlrpc.com/) into the home page for the XML-RPC [website](http://xmlrpc.com/).
