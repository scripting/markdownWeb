[Jon Udell demo'd](https://twitter.com/judell/status/1169365478482989057) a feature that lets you expand-collapse in Markdown files on GitHub. Here's [how to](https://gist.github.com/pierrejoubert73/902cc94d79424356a8d20be2b382e1ab) do it. If you enclose text in an XML <details> element it is collapsable. A <summary> sub-element provides the text that you click to expand.
