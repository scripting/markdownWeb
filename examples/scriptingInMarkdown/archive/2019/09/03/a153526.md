Going forward with the [XML-RPC in JavaScript](https://github.com/scripting/xml-rpc) project. I realized I should must include an HTTP server in the package. It's nice that you can use the protocol over any transport, and use JSON in place of XML, but there is a standard, [RPC over XML via HTTP](http://scripting.com/davenet/1998/02/27/rpcOverHttpViaXml.html). So this is what a [typical server](https://gist.github.com/scripting/43fc83d0cbfe811dcac284fa3890f291) looks like with those assumptions. Much simpler than it would otherwise be, which of course is the point of using XML-RPC. :grin:
