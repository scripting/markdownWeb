[Jon Udell](https://blog.jonudell.net/2019/09/05/products-and-capabilities/) on coding an outliners. There is a reason to go for a full outliner, because without the ability to organize code, you can't deal with the complexity of ridiculously nested code as happens with [Callback Hell](http://callbackhell.com/) in JavaScript. It's hell for some, but because I code in an outliner, it's [heaven](http://scripting.com/2019/08/19.html#a165445) for me.
