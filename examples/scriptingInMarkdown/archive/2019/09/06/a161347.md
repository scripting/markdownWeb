![](https://imgs.scripting.com/2019/06/15/kicker.png)I think I've got [persists](https://www.npmjs.com/package/persists) wrapped up pretty well. Here's the [readme](https://github.com/scripting/persists#readme). There's a [simple app](https://github.com/scripting/persists#a-simple-app), and I walk through it explaining what it does. And a more [complex app](https://github.com/scripting/persists/blob/master/examples/lotsofobjects.js). Finally solved the puzzle, how to get object database-like persistence using native JavaScript objects, using JavaScript object syntax. The key idea is that the objects are shared between the levels. One level takes care of persistence, the higher level keeps track of its data and doesn't care how it persists. I've been [pestering](http://scripting.com/liveblog/users/davewiner/2015/12/15/0640.html) friends about this for [years](https://duckduckgo.com/?q=site%3Ascripting.com+persistent+javascript&t=h_&ia=web). [Allen WB](https://twitter.com/awbjs) said look at proxies. It took a few years, but I got there.
