There is a [thread](https://github.com/signalapp/Signal-Desktop/issues/2581) on the GitHub project about this, but the fixes are expressed in terms of a beta, which I don't think I'm running. According to the About window I'm running [v1.22.0](http://scripting.com/images/2019/03/16/signalAbout.png).
