Bug fixed in [feedBase](http://feedbase.io/). If the user logs off, changes their Twitter username, then logs back into the app, the updates will go to the old username. This was a caching issue in the [davetwitter](https://github.com/scripting/twitter) package. Thanks to [vincode-io](https://github.com/vincode-io) for the excellent detective work and [report](https://github.com/scripting/feedBase/issues/40). I was able to understand the problem immediately, and it was easy to fix.
