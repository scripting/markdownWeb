I should write a howto to explain editing subscription lists in [LO2](http://littleoutliner.com/). I wrote [one](http://scripting.com/opmlHowto/dave/editorOpmlOrg/editSubscriptionLists.html) for the OPML Editor in 2008. It still runs btw, I use it, sometimes even to [edit](http://scripting.com/images/2019/06/19/nbalistinopmleditor.png) subscription lists. Two key bits for LO2: 1. You can make outlines public. Look in the File menu. 2. And you can edit the attributes of a headline, click the suitcase icon in the left margin.
