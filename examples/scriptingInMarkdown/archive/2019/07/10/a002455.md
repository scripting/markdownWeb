![](https://imgs.scripting.com/2019/07/10/smore.png)A media hack is different from a software hack. Podcasting is a media hack. Sure, there was a little software needed to get the bootstrap going. But the innovation was the combination of HTTP, MP3 and RSS. It's like a S'more, which is a "cookie hack."
