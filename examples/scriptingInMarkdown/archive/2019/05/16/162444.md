_This is a specialized tool useful to a small number of people. I'm putting it here so I can easily find it by searching, when I need it in the future._

![](https://imgs.scripting.com/2019/05/16/weTryHarder.png)As you may know I have a NPM package, [davefeedread](https://www.npmjs.com/package/davefeedread), that makes it easy to read most kinds of feeds in Node.js projects. I use it in my apps that read feeds, so when I fix a bug, I just have to add it in this one place and rebuild any app that uses it.

I [share](https://github.com/scripting/feedRead/blob/master/examples/webapp/feedreadviewer.js) it because I want people to use RSS. :rocket:

Today I was debugging an app that generates RSS, and wanted to get a close look at what davefeedread was generating, and decided once and for all to put it in a web app, to make it easy to debug a feed. Should've done it long ago.

Here's an example link:

[http://feedread.scripting.com/?url=http://scripting.com/rss.xml](http://feedread.scripting.com/?url=http://scripting.com/rss.xml)

It displays the structure that the davefeedread package returns for my feed.

Thanks to [Dan MacTough](https://github.com/danmactough) who wrote the [feedparser](https://www.npmjs.com/package/feedparser) package that this is built on.
