For serious \[\[PagePark\]\] users, it has a [command line tool](https://github.com/scripting/pagePark/tree/master/cli), and can run apps. This work was complete over a year ago but I didn't announce it because I wanted to burn it in for a while. I've been using it on a production server without issue for many months, running lots of apps. You still want to use [Forever](https://www.npmjs.com/package/forever) or something like it to be sure that PagePark stays running, but for the apps that PagePark is managing, it takes care of keeping them running. The Forever people made their great app into a Node package, that's what made this possible. I wrote my own command line tool.
