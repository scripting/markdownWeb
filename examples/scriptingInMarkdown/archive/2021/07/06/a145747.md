Web devs -- if you work in JavaScript and sometimes think of adding a feature that uses OPML but think it's too much trouble, I've put together a [toolkit](https://github.com/scripting/opmlPackage) in the form of an [NPM package](https://www.npmjs.com/package/opml) and [browser-based code](https://github.com/scripting/opmlPackage/blob/main/client/opml.js) that makes supporting OPML as simple as JSON. There's a new explosion of interest in outliners, so now is a great time to start wiring these things together to create truly world wide applications. We're on the cusp of greatness, again. Imho, ymmv, mmlm. :rocket:
