![](https://imgs.scripting.com/2020/06/18/orangeCrush.png)Something very scary just happened. There's a bug in [Drummer](http://drummer.land/) that it sometimes updates the wrong outline when an [I/O](https://github.com/scripting/instantOutlines) update comes in. This can result in [hilarity](http://thesaurus.land/?word=sarcasm) when somehow the updates overwrite the file for [Scripting News](http://scripting.com/), and it seems there is no backup. It's a bug. And bugs hurt! I looked everywhere and kicked myself virtually for not maintaining a backup of this vital file. Every time I publish there should be a copy preserved. Well, it turns out that _was_ happening. I post the outline to the instantOutlines [repo](https://github.com/scripting/instantOutlines/blob/main/outlines/scripting.opml), and thanks to the power and elegance of GitHub, there's a snapshot of [every update](https://github.com/scripting/instantOutlines/commits/main/outlines/scripting.opml), going back to when I [started](https://github.com/scripting/instantOutlines/commits/main?after=8131158da2d286bb63af971a89c286e1e6f6c217+349&branch=main&path%5B%5D=outlines&path%5B%5D=scripting.opml) doing [this](https://github.com/scripting/instantOutlines/commit/845ff95bfb4be0f23decf8293c87bd1265f2e6a3#diff-89806a2beb32ade7fba211d2a60aa14df918ef736850ccfc08a615de0a7bfefc) on [June 17](https://github.com/scripting/instantOutlines/commit/3786362d531109220bafe8f62b9689692f03f92b#diff-89806a2beb32ade7fba211d2a60aa14df918ef736850ccfc08a615de0a7bfefc). Catastrophe averted. Whew. And wow GitHub is starting to turn into a very nice network file system.
