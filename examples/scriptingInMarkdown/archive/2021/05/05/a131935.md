![](https://imgs.scripting.com/2021/05/05/manet.png)The fan art feeds from Twitter are now available as a web app, at [artshow.scripting.com](http://artshow.scripting.com/). I think that's about all the work I'm going to do on this project for now. The [GitHub repo](https://github.com/scripting/artDownloader) will update periodically with more images. I've shared the source for the [Node app](https://github.com/scripting/artDownloader/tree/main/app) that gathers the images and data about the images, and the [web app](https://github.com/scripting/artDownloader/tree/main/client) that displays the art in a web browser. There's a [public JSON file](https://raw.githubusercontent.com/scripting/artDownloader/main/data/art.json), part of the repo, that is a list of all the images, so you can create your own apps if you like. There is a [howto](http://this.how/artshow/) doc. Thanks to the [fans](https://github.com/scripting/artDownloader#the-fan-feeds) who curate these wonderful art feeds. I love it, and am glad to be able to do a small part to make the art more useful. If you have questions or comments, please open an [issue](https://github.com/scripting/artDownloader/issues/new) on the repo.
