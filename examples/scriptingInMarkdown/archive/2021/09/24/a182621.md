The [OPML package](https://github.com/scripting/opmlPackage) has a new [end-point](https://github.com/scripting/opmlPackage/blob/3b4a4e289d87ebd9cffe9d239c7a8b63b3954a4c/client/opml.js#L154) that reads an OPML file, and if it has an _urlUpdateSocket_ head-level attribute, sets up a subscription, and calls back when the outline is modified. Captures all the complex code behind the interface, so an OPML-consuming app can have instant updates with no effort. It's wonderful to see this in action, hope to have a public demo soon.
