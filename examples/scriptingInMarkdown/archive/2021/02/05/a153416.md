Thanks to the [braintrust](https://github.com/scripting/pagePark/issues/17), once again have figured it out. In the docs for [PagePark](http://pagepark.io/) we ask them to map port 80 requests to port 1339 using the [iptables](https://en.wikipedia.org/wiki/Iptables) command. But the routing was only going one way. When an outside request was coming into the server. For requests made going out of the server, the same mapping must apply. And that fixed the problem.
