About eight years ago I sat down to write a bit of software that would let me edit numerous files in a single outline. When I saved the outline they would all update in the various places they were aimed. So with one click I could update a server and its user interface, scripts that run on the server, and a documentation website on GitHub. All the associated files would be in one outline. The [outline as a file system](http://daytona.scripting.com/?q=outline%20as%20a%20file%20system&collection=scriptingnews) model.

I use it all the time for every project I do. Here's a [screen shot](http://scripting.com/images/2021/12/27/nodeEditorScreenShot.png).

It came together remarkable quickly in 2013, in Frontier. In the last few days I've rewritten the software to run in [Electric Drummer](http://docserver.scripting.com/drummer/electricDrummer.opml). The codename for the product is [Glorp](http://daytona.scripting.com/?q=glorp&collection=scriptingnews). I'm actually kind of falling in love with the name. When I wrote the initial version in Frontier in 2013 it was just for me. I called it [NodeEditor](http://daytona.scripting.com/?q=NodeEditor&collection=scriptingnews) because it was initially conceived as a way of editing Node apps. It has outgrown that name, it does much more than that now. Glorp will do for now.
