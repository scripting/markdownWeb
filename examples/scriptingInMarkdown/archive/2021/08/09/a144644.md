![](https://imgs.scripting.com/2019/09/10/drummer.png)[Back in 1998](http://scripting.com/98/04/stories/simpleCrossNetworkScript.html), we were getting ready to simplify scripting of apps that ran on other nodes on the net. I felt there was no reason function calls should be more complicated than they need to be, just because the function was on a server. Spoiler alert, we did implement this in [Frontier](http://scripting.com/2021/01/04/140651.html?title=whatFrontierIsAbout) and it was wonderful. Now the question is -- can we implement it in JavaScript, or will it require a pre-preprocessor, which is an option in [Drummer](http://drummer.land/) since we have a very thin pre-processor. I opened a thread for discussion [here](https://github.com/scripting/Scripting-News/issues/219).
