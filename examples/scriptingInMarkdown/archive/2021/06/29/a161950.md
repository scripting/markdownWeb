An [outline of my tweets](http://scripting.com/code/instantoutlinesrepo/demo/index.html?url=https://raw.githubusercontent.com/scripting/instantOutlines/main/outlines/twitter/davewiner.opml) for the last few days, with threads using the outline structure. I think this is a good way to have tweet streams flow into an outliner. Since it's entirely [OPML](http://opml.org/) and uses [GitHub](https://github.com/scripting/instantOutlines/blob/main/outlines/twitter/davewiner.opml) in a public repo, any outliner can be part of the network.
