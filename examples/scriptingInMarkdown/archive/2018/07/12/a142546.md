I'm now archiving the RSS file for Scripting News [in the GitHub repo](https://github.com/scripting/Scripting-News/blob/master/blog/rss.xml), every night, along with the content of the blog for the day (in JSON, OPML and HTML). It'll be interesting to be able to track the changes to the file over (knock wood) long periods of time. Here's the [source](https://github.com/scripting/oldSchoolNightly/blob/master/oldschoolnightly.js) of the app that does the uploading. It's proven to be very reliable. :boom:
