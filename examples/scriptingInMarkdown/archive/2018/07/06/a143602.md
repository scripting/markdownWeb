![](https://imgs.scripting.com/2018/04/10/drNick.png)Something changed somewhere and the blogging I was doing in 2012 and 2013 stopped working. Turns out that files without extensions were previously interpreted as text/html even if the returned Content-Type was text/plain. So I added a [feature](https://github.com/scripting/pagePark/blob/master/docs/config.md#setting-the-default-content-type-for-a-domain) to [PagePark](http://pagepark.io/) that lets you set the default type for a site. That was what was needed. Here's a [list of the posts](http://threads2.scripting.com/2013/march/) from March 2013 that now should work properly, again. When you have as much web history as I do, keeping things running is [a lot of work](https://www.youtube.com/watch?v=bvEexTomE1I).
