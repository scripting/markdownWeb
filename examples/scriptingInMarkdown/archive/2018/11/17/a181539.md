New feature: The [home page](http://likes.scripting.com/) of my Likes server [shows](http://scripting.com/images/2018/11/17/myLikes.png) a list of URLs that you've liked. To see the list, click the _Sign on Twitter_ button at the bottom of the page. There's a new [version](https://github.com/scripting/likes/commit/bd69d93b33a22fc246c0c09074970c744141c3c7#diff-6dca39da7c199d5eed52a31f2b11fda7) of the server with the call that returns this list. You can only see the items you've liked. The call requires an access token. Comments and questions welcome [here](https://github.com/scripting/likes/issues/1).
