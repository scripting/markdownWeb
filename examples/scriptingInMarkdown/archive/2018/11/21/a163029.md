![](https://imgs.scripting.com/2018/05/17/mrNatural.png)A journey of a thousand miles begins with a single step. Here's a [new version](http://scripting.com/code/xmlrpcbrowserclient/) of a client that runs the standard [XML-RPC](http://xmlrpc.com/) test suite from the late 90s. In theory if an implementation passed the test 18 years ago, it should still pass it today. Consider this a ping asking the question Are You There? If you use or maintain an implementation of XML-RPC, please try the test and report the result in [this thread](https://github.com/scripting/xml-rpc/issues/7). From this we'll start to rebuilt the XML-RPC clients list, showing only ones that are known to be alive.
