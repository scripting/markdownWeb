There's a new element, [source:likes](http://source.scripting.com/#1542988644000) in the [source](http://source.scripting.com/) namespace. It appears in the [RSS feed](http://xmlviewer.scripting.com/?url=http://scripting.com/rss.xml) for Scripting News. Feed readers can use the server URL to form a Like icon for each item that integrates with other feed readers. Perhaps the beginning of a way to build connections between people who read a blog via various feed readers. Updated the [docs](https://github.com/scripting/likes/blob/master/readme.md) for my Likes server to include a third [API](https://github.com/scripting/likes#api-for-the-node-app) endpoint. I'm probably going to support this in River5 to complete the circle.
