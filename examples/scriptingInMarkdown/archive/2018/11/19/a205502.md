![](https://imgs.scripting.com/2018/11/19/mrKoolAid.png)I did some work today on the [XML-RPC debugger](http://scripting.com/code/xmlrpcdebugger/). Look in the [Tests menu](http://scripting.com/images/2018/11/19/testsMenu.png). It populates the form with one of the [standard tests](https://github.com/scripting/xml-rpc/blob/master/examples/betty/betty.js) [from](http://xmlrpc.scripting.com/validator1Docs.html) [the](http://xmlrpc.scripting.com/) [old days](http://frontier.userland.com/reference/xml/xmlRpc/). It's also preconfigured to talk to betty.userland.com, the same server we used in the late 90s, with all new code, written in JavaScript running in Node. Should be 100 percent backward compatible. More work to come, but wanted to show this to you all now. Ask questions [here](https://github.com/scripting/xml-rpc/issues/6).
