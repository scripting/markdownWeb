The new releases of [River5](https://github.com/scripting/river5) and [davereader](https://github.com/scripting/reader) are out.

It felt like it was going to be a small change, but it wasn't.

That said, there are still references to fargo.io in the code. That'll take more time to shake out because this code is shared with my other projects. But the main files for displaying rivers are now in [jsdelivr](https://www.jsdelivr.com/).

Please update your [River5](https://github.com/scripting/river5) installation, [watch for problems](https://github.com/scripting/river5/issues/21) .

If you want to see all the code that's being accessed through the CDN, it's in the [River5 repository](https://github.com/scripting/river5/tree/master/includes) on GitHub.
