![](https://imgs.scripting.com/2018/04/08/stalin.png)New version of [River5](https://github.com/scripting/river5). After burning in the new feed reading package in feedBase, I made the same [fix](https://github.com/scripting/reader/blob/master/davereader.js#L752) in the [davereader](https://www.npmjs.com/package/davereader) package, which is the core of River5. If you were [seeing](https://github.com/scripting/river5/issues/20) garbled text in feeds in German, for example, this version should fix that. To update, quit the app, type _npm update_ at the command line, then restart the app.
