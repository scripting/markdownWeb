Re the [change](http://scripting.com/2018/04/02.html#a220750) I made yesterday to subscriber counts on user-feed-lists in feedBase, I changed it per this [feature request](https://github.com/scripting/feedBase/issues/27). Now we sort by name but include the subscriber count. An [example](http://feedbase.io/?username=davewiner). I think this is the more rational approach. It's useful to see the subscriber counts. Note that the counts are not the [combined](http://scripting.com/2018/04/02.html#a191743) counts, so you'll only see the counts for the specific feed URL you're subscribed to, not the combination of all the aliases.
