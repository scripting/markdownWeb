I noted early this morning tweets from [Phil Windley](https://twitter.com/windley/status/1072783216858271744) and [Chris Allen](https://twitter.com/ChristopherA) about a conference in Switzerland where they have an easy way of explaining a new "self-sovereign" identity system. At some point I want to ask the question about how we can adapt the code we have working with Twitter as an identity system with this new system. It's important that for application developers it be as easy or easier than the currently available systems.
