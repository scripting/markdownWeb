Here's a [Node app](https://github.com/scripting/oldSchoolNightly/blob/master/oldschoolnightly.js) that backs up a bunch of files from my blog onto a GitHub repository every night. So in case my servers ever go offline, there's another copy of the content, kept current automatically, on GitHub. It's good starter code for your own backup app. I rewrote it in the last couple of days to also back up the [glossary](https://github.com/scripting/Scripting-News/blob/master/blog/misc/glossary.opml) and a few [other](https://github.com/scripting/Scripting-News/blob/master/blog/rss.xml) [files](https://github.com/scripting/Scripting-News/blob/master/podcatch/subscriptions.opml) that were being copied by another process running in Frontier.
