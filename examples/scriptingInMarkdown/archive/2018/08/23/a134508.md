![](https://imgs.scripting.com/2018/08/23/whiteRabbit.png)The last couple of days I did a bunch of farting around with programmatic access to GitHub via [Node app](https://github.com/scripting/oldSchoolNightly/blob/master/oldschoolnightly.js). I came across a [readme](https://github.com/scripting/Scripting-News/blob/master/READMEx.md) that said it was done with the [English editor](http://this.how/english/), a project I vaguely remembered. I did a little digging and found the software and the [thread](https://github.com/scripting/Scripting-News/issues/48) I wrote documenting the work. The idea is to use GitHub as a blogging database. So what I did was get an instance of [Medium-Editor](https://github.com/yabwe/medium-editor) to edit stuff on GitHub. Couple that with [GitHubPub](https://www.npmjs.com/package/githubpub) that maps subdomains on locations within GitHub repos, and you've got a nice dynamic blogging system with almost $0 hosting costs. Oh if only I had the time to chase down all these [rabbit holes](https://en.wikipedia.org/wiki/Down_the_Rabbit_Hole). 🐇
