The Feeds for Journalists [OPML file](https://github.com/scripting/feedsForJournalists/blob/master/list.opml) is now available. You can use this file to subsribe to all the feeds in any feed reader. It will be updated periodically, so check back. Even better if your reader allows you to subscribe to OPML files, a drum I've been [beating](http://scripting.com/2013/08/15/feedReaderDevs) for a long time. Then you'll get the updates automatically.
