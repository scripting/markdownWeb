Yesterday Mathew Ingram, a longtime friend and professional journalist, put out a [call for feeds](https://twitter.com/mathewi/status/952214692918734848) for a reboot of his use of [RSS](https://cyber.harvard.edu/rss/rss.html).

This got me thinking. What if a community created such a list of feeds, and did it over a period of weeks or months, with discussion, and a certain amount of deliberation.

We could use the tools of open source to do this project.

So, I've set up a [new GitHub repository](https://github.com/scripting/feedsForJournalists) where we can work on that [list](https://github.com/scripting/feedsForJournalists/blob/master/list.txt) of feeds. I'll write a small piece of software that periodically turns that collection into an OPML file suitable for use in a feed reader. From there who knows what happens, but just getting a list of feeds for journalists to follow, collaboratively, while it doesn't involve much work or technical know-how, would be a major improvement over the way we all do this individually, for ourselves.

I'll post updates on this project to this [blog](http://scripting.com/).
