Kevin Marks [suggested](https://twitter.com/kevinmarks/status/1005961630709178368) looking at [json-schema.org](http://json-schema.org/) for ideas on how to handle [date and base64](http://scripting.com/2018/06/10/152333.html) values in the JSON version of XML-RPC. It gave me an idea for [another approach](https://gist.github.com/scripting/67fd46d35998a0beda354e638d563cbf#file-rpccall2-json). Basically, when JSON has a syntax for a type, just include the data (int, double, boolean, string, struct, array). When it doesn't, represent it with an object with two properties, #type and #value. The [second example](https://gist.github.com/scripting/67fd46d35998a0beda354e638d563cbf#file-rpccall2-json) illustrates this approach.
