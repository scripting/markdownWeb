More work on the [XML-RPC debugger](http://scripting.com/code/xmlrpcdebugger/). It now [looks](http://scripting.com/images/2018/06/01/xmlRpcDebuggerScreenShot.png) reasonable on an iPad. Added displays for the XML call and response. Helps to see what's going over the wire. More thinking about a JSON syntax, and what I would do differently a second time around. The original XML-RPC design was rushed, the work of four people with different perspectives and visions for where it would go. Now, 20 years later, what was speculative is now settled. And JSON has built-in syntax for the types that XML-RPC had define. So the resulting packet is smaller. I've kept the names, methodResponse, fault, etc, on the [principle](http://this.how/standards/#1497798798000) that fewer formats is better and [perfection](http://this.how/standards/#1497798834000) is a waste of time.
