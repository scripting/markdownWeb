Script runtimes should have a parameter supplied by the "supervisor" app (the one that's running the code) that says "only accept constant expressions." Anything involving a name that isn't a constant, like [NaN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/NaN) or [infinity](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Infinity) is a fatal error. Having this level of security inside the runtime is essential.
