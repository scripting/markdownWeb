![](http://scripting.com/2016/01/30/strongman.png)Edward Snowden [says](https://twitter.com/Snowden/status/972110541408952320) "unencrypted web traffic is now provably a critical, in-the-wild vulnerability." Why? Because ISPs invisibly redirect download requests of popular programs to new versions with spyware added. Better: don't download an app that runs on your local computer from a site that isn't being served via HTTPS. But it doesn't follow that _sites that don't offer downloads_ should be blocked. It's like saying drunk driving is dangerous and therefore all driving should be banned. Let's not break the web if we don't have to.
