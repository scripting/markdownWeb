![](https://imgs.scripting.com/2018/09/05/darwin.png)[opmlToGitHub](https://github.com/scripting/opmlToGitHub) is a new demo app that reads an OPML file, converts it to Markdown and uploads it to GitHub. I think outliners are a great way to write readme files, that's how I've always done it. I just added this feature to my nightly archive app, and created this little demo app as a byproduct. It contains a fair amount of [code](https://github.com/scripting/opmlToGitHub/blob/master/opmltogithub.js) that might prove useful in other apps. MIT license. ✓
