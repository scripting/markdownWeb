I chose to write software and create content for the web because there was no platform vendor who could break my software or writing. Even if HTTPS was a great idea, and worth the investment, if there was a company trying to _force_ me to use it, I would resist. I'd rather let my software and writing disappear than submit to another corporate platform vendor. I was finished with that a long time ago. So as long as you can read [Scripting News](http://scripting.com/) you know that the web is still basically an open and uncontrolled platform. The day you can't, you know it isn't (or Amazon S3 might be down, that's always a possibility).
