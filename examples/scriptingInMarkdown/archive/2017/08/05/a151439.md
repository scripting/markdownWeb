![](http:///scripting.com/images/2017/08/05/loveRss.png)If you're reading RSS and Atom feeds in Node apps, you need [feedparser](https://github.com/danmactough/node-feedparser), written by my friend Dan MacTough. I've been using his code in my own [River5](https://github.com/scripting/river5) for years. It's solid and dependable. As a gesture of gratitude I published [example code](https://github.com/scripting/feedParserDemo) yesterday that helps you get started with feedparser.
