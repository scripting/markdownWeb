As I [reported](http://scripting.com/2017/08/06.html#a122101) yesterday I have been modularizing my Node work by creating packages of reusable code. The first one I want to show you is called [opmlToJs](https://github.com/scripting/opmlToJs). It does two things well:

1.  Parses an OPML string and turns it into a JavaScript object.
    
2.  Takes one of those objects and turns it turns it back into an OPML string.
    

The JSON object it produces is set up the way all my outline-processing tools in JavaScript expect them, so it works with the [outlineBrowser](https://github.com/scripting/outlineBrowser) toolkit and many others.

If you have to consume OPML or generate it, [opmlToJs](https://github.com/scripting/opmlToJs) makes it easy.

[OPML](http://opml.org/) is a standard XML-based file format used for outlines, presentations and lists for RSS feed readers. [River5](https://github.com/scripting/river5) uses OPML to import and export feed lists. [Fargo](http://fargo.io/) and [Little Outliner](http://littleoutliner.com/) use OPML as the file format. OPML has been around [since](http://scripting.com/davenet/2000/09/24/opml10.html) 2000.

If you have any questions or suggestions, please post an [issue](https://github.com/scripting/opmlToJs/issues) on the GitHub project.
