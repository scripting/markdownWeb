When I started programming seriously in JavaScript, I did what a lot of programmers do, I started a _utils_ file where I put all the general-purpose routines I like to have around.

That's what [daveutils](https://www.npmjs.com/package/daveutils) is. An NPM package of handy JavaScript [functions](https://github.com/scripting/utils/blob/master/daveutils.js).

Frontier programmers will find these functions immediately familiar. They are borrowed from the builtin verb set of [Frontier](http://scripting.com/2021/01/04/140651.html?title=whatFrontierIsAbout). And of course those routines were borrowed from the programming I did on the Mac before there was a Frontier. So these names go a long way back.

BTW, this is the second in the series of NPM packages I'm going to roll out here on [Scripting News](http://scripting.com/). The first was opml2JS, [introduced](http://scripting.com/2017/08/07.html#a093801) on August 7.
