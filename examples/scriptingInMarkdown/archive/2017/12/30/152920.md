On GitHub, a [report](https://github.com/scripting/Scripting-News/issues/56) of errors in permalinks in sub-items of titled items.

1.  First, thanks for posting an issue there. I can see that the system is working. That was exactly the right thing to do. (It also would have been cool to use the Discuss tab.)
    
2.  This wasn't a case of a programming error, more a case of a distracted programmer, who forgot there are permalinks at lower levels to consider.
    
3.  So now, when it's generating the text subordinate to a titled item, it uses the permalink pointing to the title to form the permalink for subs.
    
4.  I have the new code running and will now try my first real build with the new code (already tested locally).
    
5.  It seems to work. Now the [permalink](http://scripting.com/2017/12/30/152920.html#a164101) to this paragraph points to the individual page for the titled item.
