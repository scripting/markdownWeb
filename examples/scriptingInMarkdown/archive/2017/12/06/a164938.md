![](https://imgs.scripting.com/2017/12/06/bizarroSuperman.png)I have a new [app](http://scripting.com/english/) for you to try out. It's called [English](http://this.how/english/). It's an editor that runs in the browser that can create and edit a Markdown document in a GitHub repository. It's designed for editing docs and readmes, and to make it possible for less-technical writers to participate in GitHub-hosted open source projects.
