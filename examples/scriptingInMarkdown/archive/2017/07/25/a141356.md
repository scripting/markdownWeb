I use [node-emoji](https://www.npmjs.com/package/node-emoji) to process the emoji [short codes](https://www.webpagefx.com/tools/emoji-cheat-sheet/) on my [blog](http://scripting.com/). I [asked](https://github.com/omnidan/node-emoji/issues/44) for a feature that allowed me to enclose emoji in a [span](https://www.w3schools.com/tags/tag_span.asp) so I could make them a bit larger using [CSS](https://www.w3schools.com/html/html_css.asp). They added the [feature](https://www.npmjs.com/package/node-emoji#format). _Thanks!_ :thumbsup:
