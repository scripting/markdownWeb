![](https://imgs.scripting.com/2017/07/07/cow.png)I started out thinking I would just present the items in a single feed exactly as if it were a river. The data that's been transmitted between the server and the client is the same data that's used in a river.

I had it working then I decided to look at [Evergreen](https://ranchero.com/evergreen/), because it's the first [RSS](https://cyber.harvard.edu/rss/rss.html) reader that I'm aware of that properly handles titleless posts. As you know [Scripting News](http://scripting.com/) these days is about 50-50, titled vs titleless posts. It has to work well in both cases.

So I decided to scrap the river model and take a fresh view of it. I really started to like how it feels. And most of the techniques I needed were covered well in HTML 5.

Not sure where I'm going to hook this in first. Thinking I might use [Electric River](http://this.how/electricRiver) as a base, because it's so self-contained.
