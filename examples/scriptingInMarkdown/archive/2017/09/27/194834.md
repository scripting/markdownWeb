This [howto](http://my.this.how/users/davewiner/myOutlines/howtosInLittleOutliner.opml) shows how to publish howto's in [Little Outliner](http://littleoutliner.com/).

I added a [section](http://my.this.how/users/davewiner/myOutlines/howtosInLittleOutliner.opml#1506529449000) on customizing the howto's using CSS.

Fixed a bug in [Little Outliner](http://littleoutliner.com/). If you deleted a file-level attribute, if would not save the deletion in the OPML file. v1.68a.

I used PagePark to implement this feature. [Here's how](https://github.com/scripting/pagePark/issues/9) I did it.
