![](http://static.scripting.com/larryKing/images/2014/05/25/goodHumor.gif)My project for the day is to get [River5](https://github.com/scripting/river5) to support [RSS-in-JSON](https://github.com/scripting/Scripting-News/blob/master/rss-in-json/README.md) feeds. I want to support [JSON Feed](https://jsonfeed.org/) format as well, but RIJ is a straight line. I basically already have support for it in River5, because the structure is just RSS. (And of course since it's a [Node](https://nodejs.org/) app, it's all converted to a JS object before processing, which is basically JSON.) I've LOL'd about 15 times while getting this together. It's like [factoring](https://en.wikipedia.org/wiki/Factorization) in mathematics. Lots of "it just works" moments.
