![](https://imgs.scripting.com/2017/06/06/goose.png)An idea. I sent this to my friend [Dan MacTough](https://twitter.com/danmactough?ref_src=twsrc%5Egoogle%7Ctwcamp%5Eserp%7Ctwgr%5Eauthor) who wrote the [FeedParser](https://github.com/danmactough/node-feedparser) package for Node that I use in [River5](https://github.com/scripting/river5). "How about a package that compiles XML text into a JavaScript object exactly as [JSON.parse](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/JSON/parse) does." I got this idea from reading promotional material for the [JSON Feed](https://jsonfeed.org/) project. One of their concerns is that XML parsing is too hard. Okay, that's feedback. I think they're right. So let's make it as easy. Easy is good. Why not?
