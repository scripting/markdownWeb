If you're reading [OPML](http://opml.org/) files in Node apps, the new [opmlToJs package](https://github.com/scripting/opmlToJs) is the way to go. I'm using it in [PagePark](http://pagepark.io/) to serve OPML files that are then rendered through in-page JavaScript. Works great. It's how I did the [Electric River howto](http://this.how/electricRiver). I expect to use it for lots of docs. (Also updated [rssjs.org](http://rssjs.org/) to use the new design.)
