It's been a while since I asked about writing into AI chatbots -- ie writing something designed to be queried via something like [ChatGPT](https://chat.openai.com/chat), or ideally, ChatGPT itself. A few bullet points follow.

*   I already have a writing tool that I use for everything.
    
*   I figure by now a service probably exists that can ingest [RSS](https://cyber.harvard.edu/rss/rss.html) or (ideally) [OPML](http://opml.org/) -- and have it be processed and kept updated as things change.
    
*   I have a sizable documentation project coming up, and I'd like to, if possible, start off with the new medium. I think we can make docs that work much better.
    
*   Of course I asked ChatGPT itself but it was [no help](https://chat.openai.com/share/ed72c797-3aa8-44da-bacb-bcee5fd9902c). They said to use their API. I want to use something that uses their API. I can't spare the time to become a developer at this time.
    
*   If you know of such a service, or would like to make one -- send me an email or (better) post a [comment here](https://github.com/scripting/Scripting-News/issues/262).
