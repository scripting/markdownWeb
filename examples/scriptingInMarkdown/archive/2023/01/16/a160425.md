The WordPress user interface must be seen as a platform, a command line, and much higher level writing tools built to run on it. It should be possible to never see the UI of WordPress except for configuration and global settings, much the way you have [System Preferences](http://scripting.com/images/2023/01/16/systemPreferencesMac.png) on a Mac. This is why blogging software has languished. The software we use for blogging must fit into the One Timeline paradigm, above.
