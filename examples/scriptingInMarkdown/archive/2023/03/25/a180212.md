Here's the thing about Twitter. Since they started showing the number of impressions on every tweet, you can see how meaningless the number of followers is. You could have 66.7K followers, but [your tweet](https://twitter.com/davewiner/status/1639404110725402626) might still only get [764 views](http://scripting.com/images/2023/03/25/tweetscreen.png?nodialog). Once, a long time ago, Twitter was a flow machine. Now it's like a [dry lakebed](https://www.kpbs.org/news/local/2022/11/29/drying-california-lake-to-get-250m-in-us-drought-funding). A void. It looks like Twitter used to look, but looks aren't everything.
