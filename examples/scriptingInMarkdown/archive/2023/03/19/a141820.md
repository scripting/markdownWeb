In [FeedLand](https://docs.feedland.com/gettingstarted.md), if you're being asked to log in every time you go to the site, you're probably opening it via a bookmark that goes to the old URL. The easiest fix is to edit bookmark so it goes to [https://feedland.org/](https://feedland.org/) -- note the _https._ Another fix is to do a [hard-reload](http://scripting.com/publicfolder/chatgpt/2023/03/19/new-chat.html) of the page. This will force a new version to reload. It redirects if it gets a non https request.
