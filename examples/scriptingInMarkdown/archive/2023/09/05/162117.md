I've reached a milestone in my [wpidentity project](https://github.com/scripting/wpIdentity).

*   It's now a [package](https://www.npmjs.com/package/wpidentity), so it can be included in other servers.
    
*   There's also an [interface](https://github.com/scripting/wpIdentity/blob/main/client/api.js) for browser-based clients to call through the server to wordpress.com.
    
*   I've got a couple of simple demo apps running.
    
*   Thinking of hooking it up to [Drummer](http://drummer.land/) and/or [FeedLand](https://docs.feedland.com/gettingstarted.md).
    
*   It's a richer interface to WordPress content than [I've had](https://codex.wordpress.org/XML-RPC_MetaWeblog_API).
    
*   Apparently this is using the same API that their browser-based client, [Calypso](https://github.com/Automattic/wp-calypso), uses.
    

I have some definite ideas, but it's time for a break from development, off to schmooze with old and new Berkmanites. I'm one of the old ones -- it's been [20 years](http://scripting.com/2003/03.html) since I showed up there in 2003, believe it or not.
