![](https://imgs.scripting.com/2023/09/23/harrison.png)One of these new twitter-like services should specialize in hooking up with blogs. A chat system for bloggers? Threads hanging off each post? Cross-linking? Let's have long and short form work really well together. I know all about the technology that will make this possible, but what's important is that it's a process, not an event. We should start working on this now and keep working on it for years.
