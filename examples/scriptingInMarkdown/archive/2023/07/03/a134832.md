If you're a [Little Outliner](http://littleoutliner.com/) user, and you can still access your files, you should download them asap. Use the [command](http://scripting.com/images/2023/07/03/downloadFilesCommand.png) in the Tools menu. Then you should switch to [Drummer](http://drummer.land/). It's a significantly better version of LO2 and _does not depend on Twitter_ for identity. I think the reason it still works for some people is that we cache the login information on the server, and as long as the server doesn't restart, you can continue to use it. But the server will eventually restart, and that'll be the end of LO2. It's had a good run and Drummer has been out there for a couple of years now.
