![](https://imgs.scripting.com/2022/12/15/drummer.png)Working on a little project in [Drummer](http://drummer.land/) that uploads a file to GitHub. I went to add the code to the server, and found it was already [there](https://github.com/scripting/appServer/blob/main/appserver.js#L864). I traced my steps up the stack and found where the call is. Amazingly there's a complete Drummer verb set for GitHub, and even better, it's [documented](http://docserver.scripting.com/?verb=github.upload). Who wrote this? Me! I've been doing this too long. (Postscript: It wasn't exactly what I needed.)
