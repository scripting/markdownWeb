![](https://imgs.scripting.com/2023/07/30/birdAndHBO.png)Briefly, there's been a [standard](https://developer.twitter.com/en/docs/twitter-for-websites/cards/overview/markup) for including machine-readable metadata in web pages so that when Twitter or Facebook posts a link to the page, they can use an image, title, description and link to the source website in creating a "card" for the post. It's very easy to support in a CMS, so people tend to do it. My site has the feature.

There's a confusing story going around that Twitter was [limiting](https://mashable.com/article/x-accessibility-concerns-over-removed-headlines) this feature, or even ignoring it. It wasn't clear from the story exactly what they were doing, so [let's find out](https://twitter.com/davewiner/status/1710458267468546276).

I've added an image and description to this post. Did they come through when I [pointed to it](https://twitter.com/davewiner/status/1710458267468546276) on Twitter?

Where are you reading the post? A mobile device, desktop, some other place?

Ignore this if you got it via email, this feature doesn't apply there.

[Screen shot](https://imgs.scripting.com/2023/10/06/whatThePostLookedLikeOnTwitter.png): When I read the post in Chrome on my desktop Mac, the title and description were not shown, the image was shown, and the name of the site was shown.
