![](https://imgs.scripting.com/2023/04/24/cheshireCat.png)[BlogBrowser](http://blogbrowser.org/docs.opml) started out as a [test app](https://blogbrowser.org/) for the WordPress.com API, and over time became a nice way to create and edit posts. Of course there must be many tools out there that do what this does, not claiming any kind of breakthrough, just something that might be useful to some people. I've been using it myself to write WordPress blog posts. If you have comments or questions, post them [here](https://github.com/scripting/Scripting-News/issues/274).
