![](https://imgs.scripting.com/2019/09/10/drummer.png)I just redirected from [drummer.scripting.com](http://drummer.scripting.com/) to [drummer.land](https://drummer.land/). So you can use Drummer once again. It's been down [since Feb 4](http://scripting.com/2023/02/04.html#a162658), while it was retooled for email-based identity and HTTPS. It all appears to work as well as it did when we previously did identity with Twitter. It has been a really [stressful](http://scripting.com/2023/02/10/023900.html) couple of weeks, while working with developers on getting FeedLand open source release out, I had to also rip up Drummer and put in a new identity system. All the code was written but it still was an ugly transition, one you hope to never have to do. [Report problems here](https://github.com/scripting/drummerSupport/issues/178). Remember to give us steps to reproduce. If we don't understand what the problem it'll be hard to fix it.
