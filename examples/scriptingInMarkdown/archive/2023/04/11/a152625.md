![](https://imgs.scripting.com/2023/04/11/fruitCocktail.png)[Substack Notes](https://substack.com/notes) is open. I have an [account](https://substack.com/profile/1497021-dave-winer/note/c-14454947) that I started a long time ago when I was trying out their newsletter publishing system. I ended up writing my own, because I didn't want to be locked in to using their editor. I like that I can edit my posts. Is there a character limit? I don't know. Can posts have titles? Where is the RSS feed for my posts? Does it support ActivityPub? Is there an API? The user interface is remarkably close to Twitter.
