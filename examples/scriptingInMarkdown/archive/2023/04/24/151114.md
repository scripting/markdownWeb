Truth be told, the FeedLand platform has been ready to be released as open source for some time.

[https://github.com/scripting/feedland](https://github.com/scripting/feedland)

But I haven't been focused on that kind of stuff, so I didn't want to create an expectation that there would be a lot of support. That's still true, but the product deserves to be out there, so very quietly last week I made the feedland repo public.

The [SQL commands](https://github.com/scripting/feedland/blob/main/database/database.md) that create the FeedLand database.

I decided today was the day to [post](http://scripting.com/2023/04/24/151114.html) about it, because I have an [issue](https://github.com/scripting/feedlandInstall/issues/31) with the database that I want to ask questions about from people with expertise in MySQL, and can't do that publicly without referring to bits that are in that repo.
