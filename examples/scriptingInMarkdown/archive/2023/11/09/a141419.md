![](https://imgs.scripting.com/2023/11/09/bowHunter.png)[Feed Hunter](https://github.com/scripting/reallysimple/tree/main/demos/feedhunter) is a new NPM package that looks for a feed, starting with the address of an HTML file. We first look for feeds that are [linked into](https://dri.es/rss-auto-discovery) the HTML source code. If we don't find a working feed there, we [look in 27 common locations](https://github.com/scripting/reallysimple/blob/main/demos/feedhunter/feedhunter.js#L56) where feeds are often found. And btw, there's a new version of [FeedLand](https://docs.feedland.com/gettingstarted.md) that uses this package, so we do better at finding feeds. Thanks to the [Indieblog](https://indieblog.page/) site which keeps a great [list](https://indieblog.page/export) of blogs with feeds. We used that info to come up with our list of default locations. We also used the list of feeds people have subscribed to in FeedLand.
