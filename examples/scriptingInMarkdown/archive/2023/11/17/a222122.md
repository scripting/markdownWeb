![](https://imgs.scripting.com/2020/08/09/gary.png)We're starting to work with people on _artcasting._ The idea is we want to send visual art over RSS 2.0 feeds. Photographs. Paintings. News. The consensus seems to be that we should use the [enclosure](https://cyber.harvard.edu/rss/rss.html#ltenclosuregtSubelementOfLtitemgt) element, as with podcasting. In this case, if the type begins with "image/" then an _artcast_ viewer should handle it, and others should ignore it. We were at this place with podcasting in 2001, and needed some examples, so we had a feed of [Grateful Dead music](http://scripting.com/misc/fromDaveOfsCom/rss/gratefulDead.xml) to start using the technology. Here's the artcasting [test feed](http://scripting.com/misc/artfeed.xml). Try subscribing to it in a feed reader you like. Hopefully it either ignores the enclosure or it does the right thing with it, displays it. Here's a [thread](https://github.com/scripting/Scripting-News/issues/278) for comments, questions and screen shots.
