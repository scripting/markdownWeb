I think a basic hookup to a chatbot is going to become part of the [textcasting](https://textcasting.org/) spec pretty quickly. So far the best one I've seen is Guy Kawasaki's. I want to be able to ask for a list of things I've written on a given topic, and to be able to ask the questions in the same straightforward way I ask ChatGPT.
