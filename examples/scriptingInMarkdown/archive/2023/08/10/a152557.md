![](https://imgs.scripting.com/2017/09/12/pitcher.png)[Braintrust query](https://github.com/scripting/Scripting-News/issues/268): Back in July 2022, I [wrote](http://source.scripting.com/#1653758422000) about supporting Markdown in RSS feeds. This is something [FeedLand](https://docs.feedland.com/gettingstarted.md) does, as a feed reader and editor. I would love to see all content editors and feed readers support it. One product in particular I'd like to support Markdown is WordPress. The challenge is to figure out how to convert the HTML in a post to Markdown and then to get a [source:markdown](http://source.scripting.com/#1653758422000) element in the corresponding item in the feed. Here's a [checklist](http://scripting.com/2022/07/19/152235.html?title=devNotesForMarkdownInRss) that explains how it works. If you have any interest in working on a plugin that does this please post something in this [thread](https://github.com/scripting/Scripting-News/issues/268). When this work I'd love to host a WordPress site that runs the plugin as a proof-of-concept and to test against.
