Heh yes I still use [Frontier](http://scripting.com/2021/01/04/140651.html?title=whatFrontierIsAbout). I do all my JavaScript programming in a suite I developed in 2014, and it's still great.

This morning, I decided to take a minute and streamline something I'm doing a lot of now that I work from two different computers. And that involved doing something like what Jake Savin did in the [same place](https://imgs.scripting.com/2023/08/17/fatpagesConfirmaddress.png?nodialog) in 2004. My comment is dated today.

![Every bit of code is a bit like a blog. ](https://imgs.scripting.com/2023/08/17/codeAsBlog.png)

PS: If you have Frontier, [download this file](http://scripting.com/2023/08/17/141013.html) and open it in Frontier to get the updated bit. It's also a historic artifact, it uses a text-based file format called [Fat Pages](http://scripting.com/fatpages/faq.html), designed to be embedded in a web page that was also the docs for the bit. We came up with [all this](https://www.google.com/search?q=site%3Ascripting.com+fat+pages) in the [1997](http://scripting.com/davenet/1997/03/31/FatPagesWithWheels.html).
