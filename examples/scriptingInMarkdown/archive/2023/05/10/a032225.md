I've been using Bluesky, it's more inviting to Twitter users than Mastodon. But most of that is cosmetics. The Mastoverse could be made easier. Factored. Facelift. I don't think it would necessarily be hard, but it might be politically controversial. Most important, there needs to be simple-to-use toolkits that support the common API between all the [A/Pub](https://en.wikipedia.org/wiki/ActivityPub) apps, so every developer doesn't have to reinvent the interface. API calls that look exactly like what the user does, create post, edit post, reply to post, view replies, get timeline, etc.
